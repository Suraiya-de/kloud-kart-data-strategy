Kloud Kart Data Strategy Engagement

Overview
This repository contains the deliverables for the DE01 Architecture Case Study involving Kloud Kart, a Ghana-based e-commerce company seeking a practical and defensible data strategy following a recent funding round.

The objective of this engagement is to identify the company's most significant operational, reporting, governance, and compliance risks, recommend a realistic architecture and operating model, and present a board-ready roadmap that fits Kloud Kart's size, team capability, and budget constraints.

Deliverables
Situation Diagnosis
Architecture Recommendation
12-Month Roadmap
Architecture Decision Records (ADRs)
Board Presentation
Improvement Beyond the Brief
